# Whack-a-Mole

Para o Projeto Final da disciplina SI401, desenvolvemos uma plataforma online, utilizando as ferramentas estudadas na disciplina (HTML, CSS, JavaScript e PHP), que permite que um jogador cadastrado (usuário) jogue partidas de uma versão específica do jogo Acerte a Toupeira. A versão do jogo a ser implementada será baseada em um tabuleiro exibido na tela, representando a área de jogo do whac-a-mole original, e seguirá regras parecidas com as da versão clássica do jogo, mas atendendo à algumas especificações.
